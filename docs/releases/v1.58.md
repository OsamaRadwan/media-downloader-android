# Media Downloader v1.58 — clean source links in saved metadata

**Device test status: APK installed and app launched on HMD Skyline (Android 15).** The Accessibility service remained enabled. Source-link privacy was verified with synthetic token-bearing links and MP4 metadata tests; a new Instagram download on the phone was not used for this check.

## Changes

- New MP4 Comment tags and JPEG EXIF UserComment fields use only a validated public post permalink. Share query parameters and fragments, including account or session tokens, are removed for TikTok, Instagram, and RedNote.
- New download records also store the clean permalink. Unsupported or malformed post links are rejected before file metadata is written.
- An existing MP4 Comment is replaced with the clean permalink when tagging; an older link is no longer appended to it.
- The feature catalog documents the privacy rule for videos, photos, Reels, and Stories.

## Verification

- All eight local Java test groups passed. Synthetic links for TikTok video/photo, Instagram post/Reel/Story, and RedNote were checked for token removal. The MP4 test verified that its saved bytes contain no synthetic share token; lookalike hosts, userinfo, ports, HTTP, and encoded paths were rejected.
- The APK built, passed signature verification, reported package `com.codex.mediadownloader` versionCode 59/versionName 1.58, and installed with `adb install -r`. The app launched and Android still reported its Accessibility service enabled.

Previously downloaded files are not rewritten by this release. Existing download history and settings remain in place.
