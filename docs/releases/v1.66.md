# Media Downloader v1.66 — current Instagram Reel

## Changes

- The download button selects the full-screen Reel's right-side Share control, even when Instagram keeps a Home-feed post in its Accessibility tree.
- Feed posts use their own lower action row. If the current view has no matching Share control, the app stops instead of downloading a different post.
- Instagram's public embed and modern page fallback must match both the copied shortcode and numeric post ID before their video stream can be saved. The fallback uses an anonymous request and keeps the muxed video-and-audio check.

## Verification

- All nine local Java test groups passed. The APK compiled, aligned, and passed signature verification.
- Installed versionCode 67/versionName 1.66 on the HMD Skyline running Android 15. Accessibility remained enabled and Thunder VPN remained active.
- Tapped the button on three distinct full-screen Reels. Each selected the current Reel's Share rail and saved a video with the creator visible before the tap. The final v1.66 sample saved as 576×1024 H.264/AAC; a frame extracted from its MP4 showed the same scene and Arabic text as the Reel on the phone.
- A Home-feed video selected its visible action row, but Instagram withheld public media from anonymous requests for that post. It failed without saving another post's video. Public access is therefore still a limitation for some playable posts.
