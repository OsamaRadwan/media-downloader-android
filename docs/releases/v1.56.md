# Media Downloader v1.56 — Instagram photo captions

**Device test status: VERIFIED for the single-photo metadata update. Story saving remains experimental.** Version 1.56 was installed on an HMD Skyline running Android 15. A NASA single-photo post saved at 1439×1455, the largest width listed in its public responsive image set. The Downloads card showed its owner and post IDs, full caption, and hashtags. The JPEG was pulled from the phone and its EXIF was checked: ImageDescription contains the caption; Artist contains `nasa`; UserComment contains the canonical Instagram post URL, title, and hashtags. Eight local Java checks passed, and the APK build, signature, package version, and on-device update were checked.

## Changes

- The ID-checked single-photo fallback now reads an anonymous Instagram oEmbed response for caption, hashtags, and owner ID. It accepts that metadata only when the media ID and owner name match the requested post and main image. If oEmbed is unavailable, the public profile remains the owner-ID fallback and no caption is invented.
- The Downloads page uses a singular photo label and result notification for one-photo posts.
- The download page includes Instagram in its description and points its prominent latest-version link to the newest APK, including prereleases.

The v1.55 phone tests also saved another single photo at 1440×1440, a two-photo album at 1000×1249 each, and feed and Reel videos at 720×1280 with H.264 and AAC. Those tests establish the best accessible renditions observed for those posts, not their original upload resolution. A second visible Instagram Story, from National Geographic, copied the exact Story link but returned no anonymous Story media, matching the earlier NASA Story result. No substitute image or linked post was saved. A live TikTok Story download has not been verified because its feed did not load on the test phone. This release is a **prerelease** until successful Story transfers can be verified.

## Install

Download `MediaDownloader-v1.56.apk` from this release. It is a debug-signed sideload APK for Android 10 or newer, signed with the same key as v1.55. Enable the Media Downloader Accessibility service and overlay permission if Android requests them.
