# Media Downloader v1.64 — stable TikTok button position after rotation

## Changes

- Returning from TikTok's rotated full-screen player now restores the download arrow to its saved portrait position.
- The button uses TikTok's current Accessibility window bounds during rotation, avoiding stale screen dimensions reported by the service.
- The overlay view is recreated when switching between TikTok portrait and landscape so the arrow redraws reliably.

## Verification

- All nine local Java test groups passed. The APK compiled, aligned, and passed signature verification.
- On an HMD Skyline running Android 15, three full-screen-to-portrait cycles restored the 133×133 button to `(15,1062)` each time. The arrow stayed visible.
- The final APK installed as versionCode 65/versionName 1.64. One final rotation returned the button to the same coordinates, with the Accessibility service still enabled.

Download `MediaDownloader-v1.64.apk` from this release. It is a debug-signed sideload APK for Android 10 or newer, signed with the same key as v1.63.
