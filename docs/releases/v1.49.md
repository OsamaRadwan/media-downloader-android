# Media Downloader v1.49

First public release of the generic Android app. The available APK is a debug-signed sideload build for Android 10 and newer.

## Highlights

- A configurable floating download arrow appears over TikTok and starts a transfer for the currently displayed post. A long press opens the app's Downloads page.
- Video downloads select an accessible playback variant and verify that the saved MP4 contains video and audio. Up to three downloads can run concurrently.
- Photo-album downloads save all listed images in order. The app checks desktop, wide desktop, and mobile page responses for distinct signed renditions, then keeps the largest image by decoded pixel dimensions for each album item.
- The Downloads page shows progress, speed, size, thumbnails, file details, source links, and actions to open saved media. Progress and result notifications are silent.
- Settings let you adjust the floating button's position, size, color, transparency, background, and icon, including imported transparent images.
- New video files include source URL, caption, and hashtags in MP4 metadata; JPEG album photos include available post details in EXIF.

## Resolution note

The app chooses among renditions TikTok exposes and allows it to fetch. On the tested 27-photo album, wide and mobile views exposed no image larger than the desktop rendition; the first photo remained 1080×2140. The creator's original upload resolution is not guaranteed.

## Install

Download `MediaDownloader-v1.49.apk` from this release and install it on Android 10 or newer. Enable the app's Accessibility service, display-over-other-apps permission, and notifications to use the floating control and see progress.
