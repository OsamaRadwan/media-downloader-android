# Media Downloader v1.67 — TikTok Story downloads

## Changes

- The floating button now finds TikTok's bottom-right Share control in the full-screen Story player. TikTok labels that control “Share,” so the prior button could not start a Story download.
- A Story tap opens its share sheet and requires a fresh link for the current Story. Video and photo links continue through the existing anonymous media resolver, resolution checks, progress, notification, and Downloads page.
- Normal TikTok post sharing is unchanged.

## Verification

- All nine local Java test groups passed. The APK compiled, aligned, and passed signature verification.
- On an HMD Skyline running Android 15, tapped the floating button over a live Hinata Clips video Story. The app copied a fresh link, downloaded the source stream, and saved a 90,966,522-byte 576×1024 MP4 with H.264 video and AAC audio. The Downloads page showed the completed file and Open video action. A frame extracted from the saved MP4 matched the Story's “On This Day” content series.
- A live photo Story was not available to verify. Photo Story links use the existing photo-post path when TikTok exposes them.
