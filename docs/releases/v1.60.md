# Media Downloader v1.60 — TikTok full-screen download button

## Changes

- The floating arrow works in TikTok's rotated full-screen video view. Tapping it briefly opens the current video's portrait post, copies a fresh Share link, starts the background download, and returns to full screen.
- TikTok landscape has its own saved side, vertical-position, and border-gap settings. The Settings preview can select that placement.
- If the current video's Share link cannot be captured, the app reports the error and attempts to restore full screen. It does not reuse a prior clipboard link.

## Verification

- All nine local Java test groups passed. The APK compiled and passed Android signature verification.
- On the HMD Skyline running Android 15, the arrow stayed visible in TikTok's rotated view. A tap copied the video then playing, returned to landscape, and completed a 28,420,734-byte MP4. The Downloads page showed H.264 video and AAC audio at an actual 960×720. TikTok's public data listed a 1440×1080 option, so this test does not establish that the original upload resolution was available.
- The phone also verified the prior RedNote clean-video path: a fresh button tap completed a 10,995,716-byte original-stream MP4 at 1100×1384 with H.264 and AAC. The saved file opened in the phone's player; the observed frame had no RedNote branding or account-name overlay.
- The final v1.60 APK installed over v1.59 and Android reported package `com.codex.mediadownloader`, versionCode 61, versionName 1.60.
