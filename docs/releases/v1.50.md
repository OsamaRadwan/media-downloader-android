# Media Downloader v1.50 — diagnostics prerelease

**Device test status: NOT TESTED.** Phone testing was deferred for this version. Local Java tests and APK compilation/signature verification passed. The Settings export journey, Android document picker, and update installation remain unverified on a device.

## Changes

- Saves failed stream attempts, terminal download failures, album-photo failures, overlay and clipboard failures, thumbnail problems, download-history persistence errors, icon-import errors, and unexpected app crashes to a bounded app-private log.
- Adds a **Diagnostics** section to Settings with a saved-event count and **Export diagnostic report** button. Android's document picker saves the report as a text file at a user-chosen destination.
- The report includes app version, Android version, device model and ABI, overlay/Accessibility/notification status, and failure events. It can be exported even when no failure has been recorded.
- Removes web URLs, local paths, long numeric IDs, and common secret values from stored event details. Logs stay on the device unless the user exports them.

The existing video and photo download behavior, download-history records, settings keys, notification routing, and saved-file format are unchanged.

Download `MediaDownloader-v1.50.apk` from this release. It is a debug-signed sideload APK for Android 10 or newer, signed with the same key as v1.49.
