# Media Downloader v1.62 — stay in TikTok landscape view

## Changes

- Tapping the download arrow in TikTok's rotated full-screen player now opens that player's own share menu and copies the current video's link without leaving landscape.
- The share menu closes after capture. A failed capture reports an error without using an older clipboard link.
- Button placement, saved settings, and other app download paths are unchanged.

## Verification

- All nine local Java test groups passed. The APK compiled, aligned, and passed signature verification.
- On an HMD Skyline running Android 15, the final APK installed as versionCode 63 and the Accessibility service stayed enabled. Tapping the arrow copied a fresh video link while TikTok's `LandscapeFeedActivity` remained on the 2400×1080 screen.
- That tap saved a 32,089,555-byte MP4 with 1024×576 H.264 video and AAC audio. The first listed 1280×720 stream had no audio, so the app selected the highest usable muxed candidate.
