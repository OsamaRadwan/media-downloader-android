# Media Downloader v1.51 — public media access

**Device transfer status: NOT VERIFIED.** The APK installed over v1.50 on an HMD Skyline running Android 15; the enabled Accessibility service remained on. Tapping the overlay on a public video copied its current share link and started a download job, but the first request to TikTok's short-link host timed out before media URLs could be resolved. The same link timed out from a separate computer network request. A completed public video or photo transfer and the anonymous visitor fallback have not been verified on this phone. Five local Java tests passed and the APK compiled and signed successfully.

## Changes

- Public video streams and photo renditions are requested without a Cookie header first. A valid public media file can complete without using visitor cookies.
- If a media address rejects direct access, the app may retry it with its own fresh anonymous visitor cookies. Rate-limit responses do not trigger extra session retries.
- Photo albums check all public renditions for each photo before considering a visitor retry when the best public image is smaller than the source-listed dimensions.
- Page resolution now keeps its anonymous cookie jar within one download job instead of installing it as a process-wide cookie handler, so concurrent jobs cannot inherit each other's visitor cookies.

The app does not use TikTok's signed-in account cookies. Anonymous requests can still be rate-limited or blocked; this behavior cannot guarantee protection from platform enforcement or access to the original upload.
