# Media Downloader v1.63 — faster TikTok landscape button

## Changes

- The download arrow now reacts immediately to TikTok player window changes when entering the rotated full-screen view.
- Rapid content updates no longer restart a visibility timer and postpone the button. They are checked at a bounded 50 ms interval.
- Saved placement, download capture, and other app behavior are unchanged.

## Verification

- All nine local Java test groups passed. The APK compiled, aligned, and passed signature verification.
- The final APK installed on an HMD Skyline running Android 15 as versionCode 64, with the Accessibility service still enabled.
- Portrait-to-landscape transitions on the phone showed the overlay window in the landscape layout and the arrow visible beside the video. The final build was checked again on a rotated TikTok video.

## Install

Download `MediaDownloader-v1.63.apk` from this release. It is a debug-signed sideload APK for Android 10 or newer, signed with the same key as v1.62.
