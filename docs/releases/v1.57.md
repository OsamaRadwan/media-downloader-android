# Media Downloader v1.57 — RedNote posts

**Device test status: VERIFIED for RedNote videos and a three-photo album.** Version 1.57 was installed on an HMD Skyline running Android 15. The enabled Accessibility service and existing download history survived the update.

## Changes

- A configurable floating arrow appears on RedNote video and photo post screens, with separate saved positions and live Settings previews. It captures the current post through Share → Copy link and downloads in the background.
- The anonymous RedNote resolver reads the post ID, creator, publish time, title, caption, tags, listed MP4 streams, and ordered photo list from a public mobile share page. It does not use the RedNote app's signed-in session.
- Photo albums compare public original HEIC assets with web renditions and save the largest decoded image that meets the post's listed dimensions. The Downloads page shows RedNote source links, progress, photo details, and retry actions.
- The same muxed MP4, audio, source metadata, silent notification, and Downloads page checks apply to RedNote videos.

## Verification

- Two RedNote video posts saved 720×1214 and 720×1280 MP4 files, each with H.264 video and AAC audio. The final Downloads card linked back to the matching RedNote post in the installed app.
- A three-photo post completed with 4284×5712 HEIC, 1080×1440 JPEG, and 4284×5712 HEIC. The actual decoded dimensions matched the dimensions listed for each image. The two original assets were retrieved anonymously without a post Referer.
- All eight local Java test groups passed; the APK compiled, was signed and signature verified, reported package `com.codex.mediadownloader` versionCode 58/versionName 1.57, and installed with `adb install -r`. The Settings page displayed both RedNote placement previews.

HEIC originals are preserved without recompression. Android's current EXIF writer cannot save attributes into HEIC, so their source URL, title, caption, and hashtags remain in the app's download record. JPEG photos embed those fields in EXIF, and MP4 videos embed them in MP4 metadata. RedNote Story downloading was not implemented or tested. Public media availability and resolution depend on each post's exposed assets. TikTok and Instagram Story saving remains experimental.
